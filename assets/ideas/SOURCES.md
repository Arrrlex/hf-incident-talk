## Brand rule summaries (for the presenter)

- OpenAI (https://openai.com/brand/, read via r.jina.ai because the page 403s): use the logo as provided; don't stretch, crop, recolour, add effects, or put it over a busy image; don't use the Blossom alone as primary branding; don't imply endorsement or partnership; don't show it more prominently than your own marks.
- Microsoft: no logo use without a licence; never alter; don't imply endorsement.
- JFrog: trademark; guidelines page could not be read (JS only). Use unaltered, referentially.
- Hugging Face: official assets offered for use in "your projects", no written terms; use unaltered.
